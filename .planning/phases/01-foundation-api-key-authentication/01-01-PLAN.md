<objective>
Create the installable Walking Skeleton for the Sure CLI: a standalone `cli/`
gem, one Thor application, an injectable runtime, a process-boundary runner, and
a machine-readable operation catalog that drives help now and completion/copyable
commands later.

Purpose: prove the packaging and dispatch layer end-to-end before any credential
or HTTP code exists, so every later plan adds behavior without re-negotiating
the gem layout (SKELETON.md decision).

Output: `cli/sure.gemspec`, `cli/exe/sure`, `Sure::CLI::{Application,Runner,Runtime,Context}`,
`Sure::Catalog`, `cli/config/operations.yml`, and `01-SKELETON.md`.
</objective>
