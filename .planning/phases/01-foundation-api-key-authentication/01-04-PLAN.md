<objective>
Deliver the credential and authentication slice: keychain-first storage with an
atomic file fallback, login/logout/status commands, scope preflight for writes,
and the small additive server field that makes `auth status` truthfully report the
authenticated user.

Purpose: this is what turns the pipeline from Plan 01-03 into a usable first-party
client. A user can install the gem, authenticate once, and stop passing
`SURE_API_KEY` on every command.

Output: `Sure::Auth::{Credential,CredentialKey,Store,FileStore,MacKeychainStore,SecretServiceStore,StoreFactory,CommandRunner,Login,Logout,Status,ScopePreflight}`,
`sure auth login|status|logout`, and the additive `user` field on `/api/v1/usage`.
</objective>
