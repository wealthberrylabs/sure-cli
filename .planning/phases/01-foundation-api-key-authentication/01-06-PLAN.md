  <action>
    Add a private `normalize_global_options(argv)` step in `Sure::CLI::Runner#call`, invoked after `reject_forbidden_api_key` has inspected the original argv and before `Application.start`. Define three frozen constants: `GLOBAL_VALUE_OPTIONS = %w[--profile --server --ca-bundle --fields]`, `GLOBAL_BOOLEAN_OPTIONS = %w[--json --table --csv --ndjson --quiet --verbose --color --no-color --insecure --no-insecure]`, and `TERMINAL_OPTIONS = %w[--version -v --help -h]`. Scan only the contiguous run of option tokens at the start of argv: for a value option take the following token as its value (support both `--profile staging` and `--profile=staging`); for a boolean option consume no value; if any terminal option appears, return the original argv unchanged; if an unknown token starts with `-`, raise `Errors::UsageError` naming the token and stating that global options belong before or after the command but must be valid. Stop at a bare `--` and return the original argv unchanged. If no leading options were collected or nothing remains after them, return the original argv. Otherwise return `rest + leading`, appending the leading options after the command and its arguments (the already-supported trailing form), preserving the relative order of the command, subcommand, positionals, and trailing options. Do not reorder tokens after `--`, do not drop tokens, and do not evaluate secrets. Keep `machine_output?` computed from the original argv so `--json` before the command still selects machine-mode errors.
  </action>
