<objective>
Close verification gap 4, the AUTH-02 partial, and the linked review findings
CR-04 and WR-01: `CredentialKey` drops the server path prefix, so two
deployments on one host share a credential slot and can receive each other's
key; the origin check ignores the prefix; and `StoreFactory#read` treats a nil
keychain result as final, hiding a file-stored credential that logout then
deletes while reporting `deleted: false`.

Purpose: credential isolation is a tenancy boundary, not a naming preference.
The fix must make identity and outbound sending agree on the same normalized
origin including its path prefix.

Output: path-aware `CredentialKey`, prefix-aware `AuthMiddleware`, and a
keychain-miss fallback that makes logout truthful.
</objective>
