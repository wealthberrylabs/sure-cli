<objective>
Build the shared HTTP and output pipeline and expose it through `sure api`. This
is the Phase 1 end-to-end proof: a real authenticated request to a Sure server,
normalized into a stable output contract, with every failure mapped to one
semantic exit code and every secret redacted.

Purpose: later phases add domain commands, but none of them may create a second
HTTP path, a second error mapper, or a second output contract.

Output: `Sure::HTTP::{Client,Connection,Response,RateLimit,AuthMiddleware,Envelope,Pagination}`,
`Sure::Errors::{Error,ExitCodes,Mapper}`, `Sure::Redactor`,
`Sure::Output::{Result,Json,Table,Selector}`, and `sure api`.
</objective>
