<objective>
Add the configuration slice: named profiles, a validated server URL with path
prefix/TLS options, a single precedence resolver, an atomic config writer, and an
environment-first API-key provider. Wire `Sure::CLI::Context` so every later
command resolves profile, server, TLS, output, and credential source exactly once.

Purpose: every HTTP command in Plans 01-03..01-05 needs one unambiguous answer to
"which server, which profile, which TLS policy, and which key?" This plan provides
that answer without letting secrets reach disk or argv.

Output: `Sure::Config::{Paths,Loader,Profile,Resolver,AtomicFile}`,
`Sure::HTTP::UrlBuilder`, `Sure::Auth::ApiKeyProvider`, and a fully wired
`Sure::CLI::Context`.
</objective>
