## Accomplishments

- `Generator#render_zsh` keeps `#compdef sure` and the `_sure()` definition, then ends with exactly one guarded stanza: `if [ "$funcstack[1]" = "_sure" ]; then _sure "$@"; else compdef _sure sure; fi`. Autoloaded from `fpath`, the body runs as `_sure` and re-enters the definition it just installed; sourced from `.zshrc`, it only registers the completion, so `compadd` never runs outside a completion context.
- `cli/test/fixtures/completion/_sure` was regenerated by executing the generator (not hand-edited), so the snapshot now records the fixed output.
- `completion_test.rb` asserts the `#compdef sure` header, the guard line, the `compdef _sure sure` registration, the absence of a bare `_sure "$@"` line, that the script ends with `fi`, and byte-for-byte fixture equality. A separate test validates `zsh -n` and `source` after `compinit` when zsh is installed.
- bash and fish renderers, outputs, snapshots, and the `bash -n` check are untouched and still green.

## Decisions Made

- Kept the `_sure()` wrapper and added one guard rather than adopting the review's "drop the wrapper" alternative: the guard satisfies both install paths from a single generated file, and the `#compdef` header alone does not make `source <(sure completion zsh)` work.
- The guard is emitted on separate lines (`if`/`_sure "$@"`/`else`/`compdef _sure sure`/`fi`) rather than one line, so the call is unmistakably inside the `if` branch and the script ends with `fi`.
- zsh availability is detected by scanning `PATH` for an executable `zsh` instead of invoking the shell, so the skip path is deterministic and produces no stderr noise.
- The source check runs `zsh -f -c 'autoload -Uz compinit; compinit -u; source "$1"' <name> <path>`, passing the temp file as `$1` so the path needs no shell quoting.
