<objective>
Complete the Phase 1 surface: full machine-readable output formats, `sure doctor`,
and catalog-driven shell completion, plus a regression suite for the "never prompt
without a TTY" rule.

Purpose: this is the polish that makes the CLI scriptable and diagnosable. Without
it, a user can make one request but cannot reliably pipe/parse it, diagnose a bad
server/TLS/key combination, or install completion.

Output: `Sure::Output::{Csv,Ndjson,FieldSelection}`, `Sure::Doctor::{Runner,Check,Result}`,
`Sure::Completion::Generator`, `sure doctor`, and `sure completion`.
</objective>
